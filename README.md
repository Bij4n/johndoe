# Fake Person Generator

A simple client-side random person generator for testing and development purposes. Generates realistic-looking fake identities with personal info, contact details, employment, online profiles, and credit card numbers.

## Features

- Random name, gender, date of birth, and age
- Contact information (email, phone, address)
- Employment details (job title, company)
- Online profile (username, password, browser user agent)
- Credit card numbers with valid Luhn check digits
- One-click copy for individual fields or entire profile
- All data generated client-side with no server required

## Usage

Just open `index.html` in your browser. Click "Generate Person" to create a random identity. Use the "Copy" buttons to copy individual fields, or "Copy All" to copy the entire profile.

## Testing

Open `test/SpecRunner.html` in your browser to run the Jasmine test suite.

## Note

All generated data is entirely fictional. Any resemblance to real people is purely coincidental. This tool is intended for software testing and development use only.
